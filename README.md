
## О себе:
Я — Python Backend разработчик. Занимаюсь созданием серверной части веб-приложений, уделяя основное внимание логике работы с данными и надежности кода.

В работе фокусируюсь на следующих задачах:

Разработка API: Использую FastAPI для асинхронных сервисов и Django (DRF) для комплексных систем.

Работа с базами данных: Пишу запросы на PostgreSQL, использую транзакции и блокировки для обеспечения целостности данных в многопользовательских сценариях.

Автоматизация и тесты: Покрываю код тестами (Pytest), упаковываю приложения в Docker и настраиваю базовые пайплайны CI/CD (GitHub Actions).
